# CKA Trainer Lab

Welcome! This scenario deploys **cka-sim** — a hands-on Kubernetes exam trainer — on a real
multi-node cluster (kind: 1 control-plane + 2 workers).

While you read this page, the background script is:

1. installing `kubectl`, `jq`, `kind`,
2. cloning the trainer repo to `/root/cka-ckad-cks-prep`,
3. creating the cluster (2-4 minutes).

You will then practice with **real kubectl commands**, graded automatically, with a
progressive hint system that teaches the *research method* — not just the answer.

**Source repo:** https://github.com/packbo/cka-ckad-cks-prep

Click **Start** when you're ready.
